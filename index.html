Using this

  • Tap a Reading to open it in Logos.
  • Talk through the question together, then tap the circle to mark the day done.
  • Tap a candle to see that week.
  • Turn on the daily reminder to get each day’s reading and question as a notification. It’s skipped if you’ve already marked the day done on that phone.
  • On iPhone, use Share → Add to Home Screen so it opens like an app and works offline.
